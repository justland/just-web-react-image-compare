# @just-web/react-image-compare

Compare two images the way GitHub's image diff does.

- **Side by side**: the two images next to each other.
- **Swipe**: one image over the other, split by a divider you drag.
- **Onion skin**: the compare image over the base image, with a slider for its opacity.

`ImageCompare` shows all three with a mode switcher.
`SideBySide`, `Swipe`, and `OnionSkin` are also exported on their own.

The components use inline styles only, so they need no CSS file and render anywhere React does,
including the Storybook manager.
